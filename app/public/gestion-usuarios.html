Gestión de Usuarios

El usuario de acceso no tiene que ser un correo — tú decides el nombre de usuario de cada persona. Aquí se asigna nombre, usuario, contraseña y rol.

Usuarios

El campo Usuario debe ser único — si dos personas quedan con el mismo, la fila se marca en rojo hasta que lo corrijas.

Nombre completo Usuario Contraseña Rol
  • El usuario puede ser cualquier nombre que asignes (ej. "roberto.sanchez" o simplemente "roberto") — no está obligado a ser un correo electrónico.
  • Tú defines la contraseña de cada persona, pero el sistema solo guarda su hash — nunca el texto plano. Al crear un usuario o darle 🎲 Nueva contraseña, la contraseña generada se muestra una sola vez en un cuadro de confirmación; cópiala ahí, porque no se vuelve a mostrar en ningún lado.
  • El Operador no lleva línea ni turno asignado — los elige cada vez que cierra un turno, porque el personal rota.
  • 🗑 desactiva al usuario (deja de poder iniciar sesión de inmediato) — no borra la fila, para conservar su historial de capturas/correcciones. Un usuario desactivado puede reactivarse desde la misma tabla.
